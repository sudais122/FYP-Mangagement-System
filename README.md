# FYP Management System

## Overview
The FYP Management System is a full-stack web application designed to manage Final Year Projects at AWKUM. It provides a centralized platform for students, supervisors, chairman, and admin to manage proposals, marks, documents, deadlines, and internships.

## Features
- Student team creation and management
- Proposal submission and approval system
- Supervisor evaluation and marks entry
- Admin control panel for system management
- Deadline management system
- Internship letter submission system
- Document management using AWS S3
- Role-based authentication system

## User Roles
- Student
- Supervisor
- Admin
- Public User

## Tech Stack
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- AWS S3
- HTML, CSS, JavaScript
- Chart.js
- PM2

## Key Modules
- Authentication System
- Student Dashboard
- Supervisor Dashboard
- Admin Dashboard
- Proposal Management
- Marks Evaluation System
- Internship Module
- Deadline Management
- Document Management

## File Storage
All files are stored securely in AWS S3, including:
- CVs
- Certificates
- Proposals
- Internship letters

## Security Features
- JWT-based authentication
- Role-based access control
- Password hashing using bcrypt
- Rate limiting for APIs
- Secure file access using signed URLs

## Deployment
- Backend deployed using Node.js and PM2
- Frontend hosted on static hosting platforms
- Database hosted on MongoDB Atlas
- File storage on AWS S3

## Project Goal
To digitize and automate the FYP process and improve efficiency, transparency, and communication between all stakeholders.
